# Telegram фан-казино бот

Бот для Telegram с игровой ненастоящей валютой: бонус `+10` раз в 5 минут, игры, топ игроков, админ-панель, общий шанс выигрыша и личный шанс для отдельного игрока.

> Важно: это бот только для фан-монет. Здесь нет реальных денег, депозитов и вывода средств.

## Что есть

- 🪙 Баланс игроков в SQLite
- 🎁 `/bonus` — `+10` монет раз в 5 минут
- 🤝 `/give @username 10` — передать монеты другому игроку
- 🎰 Игры:
  - `/casino 10`
  - `/slots 10`
  - `/dice 10 4` — ставка 10 на выпадение числа 4, выигрыш x6
  - `/coin орел 10`
  - `/crash 10 2.0`
  - `/keno 10 1 2 3`
  - `/freespin` — бесплатный прокрут раз в день
  - `/blackjack 100` или `/bj 100`
  - `/bj duel 100` ответом на сообщение игрока — дуэль по Блек Джеку
  - `/ttt 100` ответом на сообщение игрока — дуэль в крестики-нолики
  - `/roulette red 10` или `/roulette черное 10`
- 🏆 `/top` — топ игроков
  - в группе показывает топ этой группы
  - `/top global` показывает общий топ
- 👥 Хорошая работа в группах: бот отвечает на команды и учитывает игроков, которые писали команды в конкретном чате
- 📩 Некомандные сообщения пользователей из лички бота пересылаются админам; сообщения из групп админам не пересылаются
- ↩️ Админы могут отвечать пользователю реплаем на полученное от бота сообщение
- 🛠 Админ-панель `/admin` для Telegram ID из `ADMIN_IDS`
- Управление игроками:
  - просмотр карточки
  - установить баланс
  - добавить/списать монеты
  - бан/разбан
  - личный шанс выигрыша
- Управление шансами:
  - общий шанс выигрыша
  - отдельный шанс для конкретного игрока

## Установка

### 1. Создайте бота

1. Откройте Telegram: [@BotFather](https://t.me/BotFather)
2. Выполните `/newbot`
3. Скопируйте токен

Для работы в группах желательно у BotFather отключить privacy mode:

```text
/mybots → ваш бот → Bot Settings → Group Privacy → Turn off
```

Команды будут работать и с privacy mode, но отключение полезно, если позже захотите добавлять реакции на обычные сообщения.

### 2. Установите зависимости

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# или .venv\\Scripts\\activate для Windows
pip install -r requirements.txt
```

### 3. Настройте `.env`

Скопируйте пример:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен:

```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
ADMIN_IDS=7858855414,123456789
DB_PATH=casino_bot.sqlite3
BONUS_AMOUNT=10
BONUS_COOLDOWN_SECONDS=300
DEFAULT_GLOBAL_WIN_CHANCE=45
```

Можно добавить двух и более админов через запятую:

```env
ADMIN_IDS=7858855414,123456789
```

### 4. Запуск

```bash
python bot.py
```

## Админ-панель

Откройте:

```text
/admin
```

Доступ есть только у ID из `ADMIN_IDS`. По умолчанию указан:

```text
7858855414
```

В панели есть кнопки:

- статистика
- общий шанс
- найти игрока
- топ игроков
- карточка игрока с кнопками управления

Также все сообщения пользователей из лички без `/команды` бот копирует админам. Сообщения из групп админам не отправляются. Чтобы ответить пользователю, админ отвечает реплаем на сообщение, которое бот прислал в личку админу.

### Быстрые админ-команды

```text
/player ID_OR_USERNAME
/player @username
/setbalance ID_OR_USERNAME 100
/addbalance ID_OR_USERNAME 10
/addbalance ID_OR_USERNAME -50
/setchance ID_OR_USERNAME 60
/setchance ID_OR_USERNAME off
/ban ID_OR_USERNAME
/unban ID_OR_USERNAME
```

Примеры:

```text
/player 123456789
/player @username
/setbalance 123456789 500
/addbalance @username 100
/setchance 123456789 75
/setchance 123456789 off
```

## Как работают шансы

- `global_win_chance` — общий шанс выигрыша для всех игроков.
- `personal_chance` — личный шанс конкретного игрока.
- Если у игрока задан личный шанс, он перекрывает общий.
- Если личный шанс выключен, используется общий.

Шанс применяется к играм `/casino`, `/slots`, `/roulette`, `/dice`, `/blackjack` и `/bj duel`.

`/dice` работает как ставка на конкретное число 1-6 с выплатой x6. Если шанс игрока 70%, то выбранное число выпадет примерно в 70% ставок.
`/blackjack` учитывает личный/общий шанс: высокий шанс помогает получать более безопасные карты и делает дилера слабее; низкий шанс наоборот.

Дуэль: игрок отвечает на сообщение другого игрока командой `/bj duel 100`. Второй игрок принимает или отклоняет вызов кнопками. Перед созданием вызова и перед стартом дуэли бот проверяет, что у обоих хватает монет на ставку.

Пример:

- общий шанс: `45%`
- у игрока Иван личный шанс: `70%`
- Иван играет с шансом `70%`, остальные — с `45%`

## Группы

1. Добавьте бота в группу.
2. Дайте права писать сообщения.
3. Игроки используют команды: `/bonus`, `/casino 10`, `/slots 10`, `/top`.
4. Топ группы строится из пользователей, которые хотя бы раз написали команду боту в этой группе.

Если команда в группе не срабатывает, используйте формат:

```text
/bonus@username_вашего_бота
```

## Файлы

- `bot.py` — логика Telegram-бота и админ-панель
- `database.py` — SQLite база, игроки, балансы, шансы, транзакции
- `requirements.txt` — зависимости
- `.env.example` — пример настроек

## Примечания

- База создается автоматически в `casino_bot.sqlite3`.
- Баланс не может уйти ниже нуля.
- Игрок должен хотя бы один раз воспользоваться ботом, чтобы админ смог найти его по ID или username.
